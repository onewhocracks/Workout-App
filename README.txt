WORKOUT COMPANION PWA

Includes Upper A/B and Lower A/B. Every exercise has 3 sets, weight/reps logging, Easy/Medium/Hard feedback, mood before/after, rest timers, local storage, manifest, icons, and offline service worker.

INSTALL ON ANDROID
1. Upload the complete folder to an HTTPS host such as GitHub Pages, Netlify, or Cloudflare Pages.
2. Open the site in Chrome on your phone.
3. Chrome menu -> Add to Home screen / Install app.
4. Launch it from the Gym icon.

For local testing on a computer, serve this folder from localhost with a static web server.
